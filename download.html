Installation in Chrome or Edge

Download the ZIP file and extract it to a folder you can find again.

Open chrome://extensions in Chrome or edge://extensions in Microsoft Edge.

Turn on Developer mode in the extensions page.

Select Load unpacked.

Choose the extracted folder containing manifest.json.

Pin the extension if helpful. On a regular webpage, click its toolbar icon; the popup automatically attaches the floating widget to the active tab.

What is included?

  • Manifest V3 extension source.
  • Popup and on-page floating panel.
  • Click point capture and management.
  • Timeline workflow editor.
  • Settings, keyboard controls and local import/export.

Before you install

Chrome does not allow extension scripts to produce trusted operating-system mouse input. This extension dispatches synthetic DOM events. Sites may ignore them, and coordinate-based actions require the selected tab to remain visible.

For details, see the feature overview and technical limits.
