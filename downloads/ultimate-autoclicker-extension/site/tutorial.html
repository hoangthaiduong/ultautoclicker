Documentation

Learn the workflow.

Enable one webpage, place one or more draggable click points, set the interval and press Play. Timeline is optional for advanced sequences.

Getting started

1

Install the extension

Download the ZIP package, extract it, open chrome://extensions or edge://extensions, switch on Developer mode and select Load unpacked.

2

Enable a webpage

Open the page you want to use, click the extension icon. The popup automatically attaches the widget to that active page; you do not need a separate Enable click. The widget appears in its saved Panel, Mini or Tab mode.

3

Add a click point

Select Add point, then click the page element. A numbered marker appears at the selected location. You can drag the marker to reposition it. Points are fixed to page coordinates, so they stay in place while you scroll.

4

Adjust the interval

Set the interval from 1 to 60,000 milliseconds. Very small values are best-effort: browser scheduling and page load can delay the actual event rate.

5

Press Play (Timeline is optional)

Play automatically cycles through enabled points in placement order until you press Stop. For advanced tasks, open Timeline, add click actions, delays, parallel groups or repeats, then select Run workflow. Timeline is separate from the quick Play points command.

6

Run and control

Play begins the point cycle. Pause preserves the current point position and stats; Play resumes. Stop cancels the current run. Minimize changes the widget to Mini controls; the edge Tab opens Panel again without stopping the run. Close only dismisses the widget on this page; reopen it from the extension popup or shortcut.

7

Manage shortcuts

Configure in-page shortcuts in Settings. Global extension commands can be customized through Chrome's extension shortcuts settings.

8

Back up a workflow

Open Timeline and use Export workflow. To restore it, select Import and choose a valid .uacworkflow or JSON file.

Troubleshooting

The floating panel does not appear

Reload the webpage, then click the extension icon to reconnect and restore points for the same URL. Browser-internal pages, extension stores and some protected pages do not allow content script injection.

A click is ignored

Some websites require trusted physical input or may replace their DOM after a workflow is saved. Re-capture the point and check whether the target element still exists.

Why does the click rate change when I switch tabs?

Click points use page coordinates, so keep the target tab visible. The next coordinate action stops with an explanatory error when the tab is hidden. This build does not include an Awake/keep-awake mode.

My shortcut does not work

Check for conflicts with browser or operating-system shortcuts. Global shortcuts are configured in Chrome's extension shortcuts page; in-page shortcuts only work when the target page is focused.
