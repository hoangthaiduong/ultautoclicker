Help center

Frequently asked questions.

Clear answers about installation, click points, timing, background behavior, privacy and compatibility.

How do I install the extension?

Download and extract the ZIP file. Open chrome://extensions in Chrome or edge://extensions in Edge, enable Developer mode, click Load unpacked, then select the extracted folder containing manifest.json.

How do I add click points?

Open a regular webpage and click the extension icon; the popup automatically attaches the widget to the active tab. Press Add point in the floating panel, then click a place on the page. A numbered marker appears; drag it to move it. Up to 100 points are supported per page.

How do I change click speed?

Adjust the global interval in the Panel or Mini widget. The range is 1 to 60,000 ms. A 1 ms setting is best-effort and does not guarantee one click every millisecond.

Can it run in the background?

Click points use fixed page coordinates. Keep the selected target tab visible; the next coordinate action stops with an explanatory error when the tab is hidden. Chrome may throttle background timers, and this build does not include an Awake/keep-awake mode.

Does it create real mouse input?

No. A browser content script can dispatch synthetic DOM events, but it cannot create trusted operating-system mouse input. Websites that check event.isTrusted, native browser UI and some protected flows may ignore these events.

How do I use Timeline?

Timeline is optional for basic clicking. Add points and press Play to cycle through them. For advanced workflows, open Timeline and add click, delay, parallel or repeat actions, then choose Run workflow. Timeline does not replace the Play points action.

How do I use keyboard shortcuts?

Global commands are defined in the extension manifest and can be changed in Chrome's extension shortcuts settings. Page shortcuts can be changed in the extension Settings page and work while the selected webpage is focused.

Is Ultimate Autoclicker free?

The included core extension has no paid tier, account or API key. This package is a manually installed build and is not a Chrome Web Store listing.

Is my data collected?

The extension stores settings, workflows and captured points locally through Chrome storage. It does not send browsing history or page content to a remote service. Browser sync, if enabled by your browser profile, is outside this extension's local storage design.

Why does a click sometimes do nothing?

Some websites require trusted user input, use shadow DOM or cross-origin frames, replace elements dynamically, or ignore synthetic events. Re-capture the point and test on a page where you have permission to automate interactions.
