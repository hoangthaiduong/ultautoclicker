Simple setup

Start in three steps.

Place numbered targets on a webpage, set the interval, and press Play. The floating widget has three stable sizes: Panel, Mini and an edge Tab. Changing size does not change the active run or remove points.

Install the extension

Download the ZIP, extract it, then load the folder through Chrome or Edge's extension developer mode.

Add click points

Open a webpage and click the extension icon; the active tab connects automatically. Press Add point, then click a position on the page.

Build and run

Press Play to cycle through enabled points. Open Timeline only when you need delays, repeat groups or custom sequences.
